# .github

Organization-wide GitHub configuration for NewsCode.

- `profile/README.md` — the organization profile page
- `.github/PULL_REQUEST_TEMPLATE.md`, `.github/ISSUE_TEMPLATE/` — default pull request and issue templates, used by repositories that do not define their own
- `SECURITY.md`, `CONTRIBUTING.md` — default policies, which individual repositories may override

Development conventions (Biome, tsconfig, commitlint) are maintained in [`dev-config`](https://github.com/newscode-dev/dev-config).
